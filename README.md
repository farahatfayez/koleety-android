# KOLEETY AI — Android Native WebView Shell

هذا هو غلاف Android الأصلي التجريبي لمنصة **KOLEETY AI**. يفتح الغلاف `https://koleety.com/` في `WebView` آمن، ويضيف تكامل Android اللازم لاختيار الملفات، التصوير عبر كاميرا النظام، ومنح صلاحيات الصوت/الفيديو المطلوبة فقط لطلبات الويب الموثوقة.

## حدود الإصدار الحالي

الإعداد الافتراضي هو بناء اختبار آمن فقط: `applicationId` هو `com.koleety.ai.app.sandbox`، ويضيف Gradle لاحقة `.debug` إلى حزمة التصحيح. لا يحق لهذا البناء استبدال أو تحديث أي تطبيق منشور في Google Play. لا يجوز تغيير `applicationId` إلى `com.koleety.ai.app`، ولا إنشاء أو توقيع AAB إنتاجي، قبل اجتياز اختبار قبول الهاتف الشامل المعتمد.

| بند | الإعداد الحالي |
|---|---|
| الحزمة المصدرية | `com.koleety.ai.app` |
| حزمة APK الاختباري | `com.koleety.ai.app.sandbox.debug` |
| الموقع الموثوق | `https://koleety.com/` |
| حد Android الأدنى | API 21 (Android 5.0) |
| SDK المستهدف | API 36 |
| صلاحيات وقت التشغيل | `CAMERA` و`RECORD_AUDIO` فقط عند طلب صفحة موثوقة لها |
| صلاحيات التخزين/الوسائط | غير مطلوبة وغير معلنة |

## إصلاح دورة الوسائط

يحفظ `MainActivity` طلب اختيار الملف وURI صورة الكاميرا في `ViewModel` و`Bundle`. لذلك لا ينبغي أن تضيع نتيجة كاميرا النظام أو منتقي الملفات عند إعادة إنشاء النشاط بسبب تغيير إعدادات الشاشة أو إدارة Android للذاكرة. كما يستخدم مسار الكاميرا `FileProvider` و`ClipData` لمنح تطبيق الكاميرا صلاحية كتابة URI المؤقت بصورة متوافقة.

طلبات `getUserMedia` الواردة من `koleety.com` فقط هي التي تستطيع طلب الميكروفون أو الكاميرا، ويُرفض أي أصل غير موثوق. لا يستخدم الغلاف أذونات `READ_MEDIA_IMAGES` أو `READ_EXTERNAL_STORAGE` لأن منتقي نظام Android يمنح التطبيق URI مقيداً للملف الذي يختاره المستخدم.

## البناء المحلي

يتطلب البناء Android SDK API 36 وJDK 21. لا تُخزّن مفاتيح التوقيع أو ملفات `signing.properties` في هذا المستودع.

```bash
./gradlew :app:assembleDebug :app:lintDebug
```

المخرج المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

## بوابة القبول قبل أي AAB

يظل APK الناتج للاختبار الداخلي فقط. قبل تحويل حزمة الإنتاج أو توقيع AAB، ينفذ المالك **اختبار قبول هاتف شامل واحداً** يغطي فتح التطبيق، تسجيل الدخول، اختيار ملف، صورة من الكاميرا، صور المعرض، تسجيل الصوت، تحليل المحاضرة، الملخص، أسئلة MCQ، المصطلحات، وشرح الصوت. يجب أن تبقى الجلسة والنتيجة ظاهرتين بعد كل عودة من نشاط نظام Android.
